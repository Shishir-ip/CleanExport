Dimension Calculation Logic

How Output Dimensions Are Calculated

Mode Base Size Target Width Target Height
Original + Original Resolution N/A Source effective width Source effective height
Original + 1080p 1080 1080 × source ratio (if landscape) 1080 (if landscape)
16:9 + Original Resolution min(srcW, srcH) baseSize × 16/9 baseSize
9:16 + Original Resolution min(srcW, srcH) baseSize baseSize × 16/9
1:1 + 720p 720 720 720
Important: All calculations use effective dimensions (after rotation metadata is applied), not raw stream dimensions.

Filter Chain Generation

When Filters Are Added

Condition Filter Added Example
Original mode + Original resolution None 1080×1920 → 1080×1920
Original mode + Different resolution scale=W:H 1080×1920 → 720×1280
Different aspect ratio + Crop mode scale=...,crop=... 1080×1920 → 1920×1080 (cropped)
Different aspect ratio + Fit mode scale=...,pad=... 1080×1920 → 1920×1080 (with bars)
Different aspect ratio + Stretch mode scale=W:H 1080×1920 → 1920×1080 (stretched)

Validation Checks

Output Validation Pipeline

  1. File Read Check: Verify output file can be read from FFmpeg virtual FS
  2. Size Check: Verify output file size > 0 bytes
  3. Stream Check: Probe output to verify video stream exists
  4. Dimension Check: Verify output dimensions are valid (> 0)
  5. Dimension Match: Verify output dimensions match expected (±2px tolerance)
  6. Blob Creation: Create Blob with correct MIME type (video/mp4)
Error Handling: If any validation fails, the error is logged and thrown with a descriptive message. The UI will display "Export failed" instead of showing a broken download.

Summary of Fixes

What Was Fixed

  • Stream Mapping: Added explicit -map 0:v:0 and -map 0:a:0 to ensure video and audio streams are included
  • Effective Dimensions: Filter chain now uses effective dimensions (post-rotation) for all calculations
  • Rotation Handling: Properly handle rotation with -noautorotate when manual rotation is needed, otherwise let FFmpeg autorotate
  • Output Validation: Added comprehensive validation (file size, video stream, dimensions) before creating Blob
  • Blob Creation: Fixed to use proper Uint8Array copy instead of raw buffer
  • Error Handling: Added try-catch blocks with descriptive error messages
  • Logging: Added detailed logging for debugging (source dims, target dims, filter chain, validation results)
  • Filter Generation: Simplified filter logic to avoid invalid filters (no NaN, no zero dimensions)

What Was Preserved

  • Metadata cleaning (-map_metadata -1, -map_chapters -1)
  • H.264 encoding with configurable CRF
  • AAC audio encoding
  • Fast-start MP4 container
  • Visual cleanup regions
  • Progress tracking
  • Checksum generation
