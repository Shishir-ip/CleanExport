This document demonstrates the Metadata Editor feature added to CleanExport.

UI Placement

Where the Metadata Editor Appears

The Metadata Editor is a collapsible section on the Settings page, positioned after the Visual Cleanup section:

  1. Upload video
  2. Analyze video
  3. Go to Settings page
  4. See sections in order:
    • Processing Settings (aspect ratio, quality, etc.)
    • Aspect Ratio Preview
    • Visual Cleanup
    • Metadata Editor ← NEW
    • Output Summary

The Metadata Editor is collapsed by default, so the UI looks almost identical to before when not using the feature.

Test Scenarios

Scenario 1: Default Behavior (No Metadata Editor)

User Action: Upload video, leave metadata editor collapsed, process

Expected Result:

  • Video processes normally
  • All metadata removed (existing behavior)
  • Output plays correctly
  • No metadata editor UI visible

✅ Works exactly as before

Scenario 2: Privacy Clean Preset

User Action: Upload video with GPS and author metadata, select "Privacy Clean"

FFmpeg Command:

ffmpeg -i input.mp4 \
  -map 0:v:0 -map 0:a:0 \
  -map_metadata -1 -map_chapters -1 \
  -metadata author= \
  -metadata artist= \
  -metadata comment= \
  -metadata gps_latitude= \
  -metadata gps_longitude= \
  -metadata country= \
  -metadata city= \
  -metadata creation_time= \
  -metadata make= \
  -metadata model= \
  -c:v libx264 -crf 20 ...

Expected Result:

  • Personal metadata removed
  • GPS coordinates cleared
  • Device information removed
  • Video plays correctly
  • Dimensions unchanged

✅ Privacy-focused export

Scenario 3: Custom Metadata

User Action: Select "Custom", set title to "My Video", author to "John Doe", clear GPS

FFmpeg Command:

ffmpeg -i input.mp4 \
  -map 0:v:0 -map 0:a:0 \
  -map_metadata -1 -map_chapters -1 \
  -metadata title=My Video \
  -metadata author=John Doe \
  -metadata artist=John Doe \
  -metadata gps_latitude= \
  -metadata gps_longitude= \
  -c:v libx264 -crf 20 ...

Expected Result:

  • Title set to "My Video"
  • Author set to "John Doe"
  • GPS coordinates cleared
  • Video plays correctly
  • Dimensions unchanged

✅ Custom metadata applied

Scenario 4: Portrait Video with Metadata

User Action: Upload 1080×1920 video, keep Original aspect ratio, edit metadata

Expected Result:

  • Output is still 1080×1920 (portrait)
  • No black bars
  • Metadata changes applied
  • Video plays in portrait orientation
  • Aspect ratio preserved

✅ Aspect ratio and metadata both work

Reset Functionality

Reset Metadata Button

The "Reset Metadata Settings" button at the bottom of the Metadata Editor:

  • Restores metadata settings to defaults
  • Does NOT reset video processing settings
  • Does NOT reset aspect ratio
  • Does NOT reset quality settings
  • Does NOT reset resolution
  • Does NOT reset audio settings
  • Only affects metadata editor state

✅ Isolated reset functionality

Integration Points

How Metadata Editor Connects to Export Pipeline

  1. UI Layer: MetadataEditor component captures user input
  2. State Layer: metadataSettings state in App.tsx
  3. Conversion Layer: buildMetadataArgs() converts settings to FFmpeg arguments
  4. Processing Layer: processVideo() adds arguments to FFmpeg command
  5. Output Layer: FFmpeg generates video with custom metadata
Critical: The metadata arguments are added AFTER the existing -map_metadata -1 flag, which first clears all metadata, then the custom metadata is added back.
