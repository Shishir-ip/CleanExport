Crop Position Controls

Positioning System

The crop position is stored as normalized coordinates (0 to 1):

  • X: 0.0 = left edge, 0.5 = center, 1.0 = right edge
  • Y: 0.0 = top edge, 0.5 = center, 1.0 = bottom edge

Position Controls:

  • Center Crop: Resets to X: 0.5, Y: 0.5
  • Directional Arrows: Move crop by 5% increments
  • Drag: Click and drag to reposition

Example Positions:

Position X Y Description
Center 0.5 0.5 Default position
Top-Left 0.0 0.0 Crop from top-left corner
Top-Right 1.0 0.0 Crop from top-right corner
Bottom-Left 0.0 1.0 Crop from bottom-left corner
Bottom-Right 1.0 1.0 Crop from bottom-right corner

Processing Order

Filter Chain Construction

The crop filter is applied in the correct order:

  1. Rotation: Handle source orientation (if needed)
  2. Video Crop: Apply user's crop factor and position
  3. Aspect Ratio: Convert to target aspect ratio (if different)
  4. Scale: Scale to target resolution (if needed)
  5. Background: Add padding for Fit mode (if needed)
  6. Encode: Final encoding with H.264/AAC
Critical: When Crop = 1×, no crop filter is added, and the existing processing path is used unchanged.

FFmpeg Command Examples

Example 1: No Crop (1×)

ffmpeg -i input.mp4 \
  -map 0:v:0 -map 0:a:0 \
  -map_metadata -1 -map_chapters -1 \
  -c:v libx264 -crf 20 -preset medium -pix_fmt yuv420p \
  -c:a aac -b:a 192k -ac 2 \
  -movflags +faststart \
  output.mp4

No crop filter - existing behavior preserved

Example 2: 1.5× Crop, Original Aspect

ffmpeg -i input.mp4 \
  -map 0:v:0 -map 0:a:0 \
  -map_metadata -1 -map_chapters -1 \
  -vf crop=720:1280:180:320 \
  -c:v libx264 -crf 20 -preset medium -pix_fmt yuv420p \
  -c:a aac -b:a 192k -ac 2 \
  -movflags +faststart \
  output.mp4

Crop filter applied - zooms into center of frame

Example 3: 1.5× Crop + 16:9 Conversion

  • No unnecessary resizing

  • No excessive sharpening
